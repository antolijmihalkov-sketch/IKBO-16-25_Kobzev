# Практическая работа №2 — вариант 13

Инструмент визуализации графа зависимостей пакетов **NuGet (.NET)**.
Получение данных выполняется прямыми HTTP-запросами к NuGet V3 Flat Container
с использованием стандартной библиотеки Python (`urllib`, `json`, `xml`).
Менеджеры пакетов и сторонние библиотеки для получения зависимостей не используются.

## Требования
- Python 3.10 или новее
- Интернет для реального режима
- Сторонние Python-пакеты не требуются

## Запуск
Из корневой папки проекта:

```bash
python -m src.main
```

Windows: запустить `run.bat`.

## Настройка
Параметры находятся в `config.ini`:
- `package_name` — ID пакета NuGet;
- `repo_url` — URL NuGet Flat Container;
- `test_mode` — `true` для тестового графа, `false` для NuGet;
- `test_repository` — JSON-файл тестового графа;
- `ascii_tree` — вывод ASCII-дерева;
- `max_depth` — максимальная глубина DFS;
- `filter_substring` — исключаемая подстрока в имени пакета;
- `reverse_dependencies` — вывод обратных зависимостей корневого пакета;
- `output_dir` — каталог диаграмм.

Для реального NuGet-режима установите `test_mode = false`.
Пример пакета: `newtonsoft.json`.

## Формат тестового репозитория
JSON-объект: ключ — пакет, значение — массив его прямых зависимостей.
Названия в демонстрационных сценариях — большие латинские буквы.

## Результат
Приложение печатает список прямых зависимостей (в реальном режиме), граф,
при необходимости ASCII-дерево и обратные зависимости. В `diagrams/` сохраняются
Mermaid-файл `.mmd` и SVG-изображение `.svg`.

## Тесты
```bash
python -m unittest discover -s tests -v
```

## Демонстрационные сценарии
- `simple.json` — обычный граф с общей зависимостью;
- `cycle.json` — циклическая зависимость;
- `depth.json` — проверка ограничения глубины;
- `reverse.json` — проверка обратных зависимостей.

## Ограничения реализации
В NuGet `.nuspec` зависимости могут задаваться в разных группах целевых платформ.
Текущая учебная реализация собирает уникальные зависимости из всех групп, поэтому
она показывает объединённый граф, а не граф для одной выбранной платформы.
При необходимости точного сравнения со штатным инструментом нужно выбирать
одинаковую целевую платформу и конфигурацию восстановления пакетов.
